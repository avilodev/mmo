# 3D World Implementation Plan (movement, jumping, combat)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The server and the client both know the world in 3D. Characters walk ramps and stairs, move over and under stacked surfaces, jump and fall. Melee, abilities, NPC attacks, projectiles, telegraphs, zones, loot and interaction ranges all respect height.

**Architecture:** One pure "spans" module answers what can be stood on at (x, y). One pure "motion" module (`world_motion`) steps a body's `z`, `vz` and grounded flag, and is shared by the client (prediction) and the server (validation). The server's existing 2D code is left alone and keeps running first. Horizontal formulas (ranges, cones, circles, AI distance, interest, speed budget) are unchanged: every place that decides "is this target in reach" gets one added height check (`world_vertical_ok`, a vertical cylinder), and every 2D spatial query is still used as the coarse filter. Projectiles are the one thing that becomes truly 3D.

**Tech Stack:** C (server, client), Python/Blender (`bpy`) for the bake, `make` test targets in each tree.

**Spec:** `docs/superpowers/specs/2026-10-03-3d-movement-design.md` (amended by Task 0; this plan is wider than the spec: combat, jumping and projectiles are in scope).

## Decisions made while planning

Task 0 records these in the spec.

1. **Spans live in a sidecar file** `world_spans.bin` beside `world.dat`, not inside it: `world.dat` is mapped read-only with an exact size check, and the clean 2D path must not be at risk. A tile with no record is flat open ground at `z = 0`.
2. **The flat collision layer becomes "solid iff the tile has no walkable span"**, so every existing 2D check stays a valid coarse filter.
3. **The speed budget stays on the xy distance** (existing code, unchanged). `z` is determined by the simulation, not chosen by the client.
4. **Vertical motion is a shared deterministic simulation.** Fixed 1/60 s steps; gravity 420, jump speed 160 (apex about 30 units, 1.4 m), terminal speed 900, all units per second. The client predicts; the server replays the same steps over the time since the last move packet and accepts the client's `z` if it matches a state within a +-5 step window (`WORLD_AIR_SLACK_STEPS`) and 8 units (1 unit when grounded). A cheat above that is `MOVE_REJECT_HEIGHT` and a correction.
5. **Combat uses vertical cylinders.** Reach in height is `WORLD_VREACH` = 48 units (a little more than a 40-unit body, so a stair or a ramp never breaks melee, while a storey of 70+ does). Projectiles fly in 3D and hit by height overlap with the body.
6. **Walking off an edge is a fall, not a rejection.** Walking into a rise taller than a step, or onto a tile with no floor, is a wall.
7. **Projectiles stop at solid ground and walls.** Today they fly through everything; with height that would mean shooting through floors. This is a deliberate behaviour change; Task 12 flags it.
8. **Deliberately left horizontal:** chat range, interest and broadcast radius, party kill-share range, the spatial grid (it stays 2D; a query is a column and the height check filters it), NPC pathfinding between levels (NPCs have none today), fall damage.

## Review Focus

The inputs the spec implies but a normal task test would not exercise, most likely first. Each has a pinning test in the owning task.

1. A client built before this change. -> Task 5: version 10 is refused at login; handlers never read a short packet.
2. A target directly above or below, same x and y (a balcony over the courtyard). -> Tasks 9-13: no melee, ability, telegraph, zone, contact, aggro or pickup reaches 100 units up; a stair-height difference of 24 still does.
3. A saved character whose stored `z` matches no surface (world regenerated). -> Task 6: login snaps to the nearest floor instead of rejecting every move.
4. A jump with network jitter (a late or early packet) versus a real height cheat. -> Task 4: a mismatch of 2 steps passes, 30 steps and a 20 unit lie are `MOVE_REJECT_HEIGHT`.
5. Jumping under a deck, next to a tall ledge, or off a platform. -> Task 3: head stops at the ceiling, a rise taller than a step is a wall, and a walk off the edge lands on the floor below.
6. Projectile aimed up a ramp, down onto a bridge, or into a floor. -> Task 12: it follows the slope, hits by height overlap, and is destroyed inside solid.
7. Spans file missing, truncated or for a different world. -> Tasks 1 and 8: loader refuses it, the world stays flat, a non-zero `z` is rejected, and the server logs why and does not crash.
8. An NPC that would step off a ledge or onto a tile with no floor. -> Task 7: treated as a wall; an NPC never holds a `z` its position cannot hold.

  - `void world_spans_init(int width_tiles, int height_tiles, int tile_size);` resets to flat and sets the world extent.
  - `int  world_spans_load(const char* path);` 1 on success; on failure returns 0 and leaves the previous tables untouched.

  - `void world_spans_shutdown(void);`

  - `int  world_spans_reach(float x, float y, float from_z, float* out_z);` 1 = a span floor within `WORLD_STEP_HEIGHT` of `from_z` with `WORLD_BODY_HEIGHT` clearance exists. **Returns 1 on success, unlike `world_collision_check*` which returns 1 when blocked.**
  - `int  world_spans_reach_box(float x, float y, float half, float from_z, float* out_z);`
  - `int  world_spans_walk(float x0, float y0, float z0, float x1, float y1, float half, float* out_z);` 1 when every half-tile sample from the origin (excluded) to the destination is reachable in turn; `out_z` is the final floor.
  - `int  world_spans_snap(float x, float y, float hint_z, float* out_z);` nearest usable floor to `hint_z` with no step limit; 0 when the column has none.
  - `int  world_spans_fits_box(float x, float y, float half, float z);` 1 when each of the four corner columns has a span holding a body standing at `z` (floor within one step of `z`, a body of headroom above `z`).
  - `int  world_spans_free_box(float x, float y, float half, float z);` 1 when each corner column has a span whose floor is at most one step above `z` and that leaves a body of headroom above `z`. The body may hang in the air above that floor. Used for airborne moves and walking off an edge.
  - `int  world_spans_floor_between(float x, float y, float half, float z_lo, float z_hi, float* out_z);` the highest floor `f` of the centre column with `z_lo <= f <= z_hi` on which the box fits (`fits_box` at `f`). 0 when none.
  - `int  world_spans_free_point(float x, float y, float z);` 1 when `z` lies inside some span's clear interval (`floor <= z < ceil`). Used by projectiles.

- [ ] **Step 1: Write the format header**

`mmo_server/common/include/world_spans_format.h`:

```c
#ifndef WORLD_SPANS_FORMAT_H
#define WORLD_SPANS_FORMAT_H

// The sidecar beside world.dat: what can be stood on, and where.
// Native-endian, like world.dat. Layout:
//   header, 32 bytes: magic[8], u32 version, i32 width, i32 height,
//     i32 tile_size, u32 tile_count, u32 span_count
//   tile records, 12 bytes each: u32 tile_index, u32 first_span,
//     u32 span_count. Sorted by tile_index, no repeats, and first_span
//     runs on from the previous record.
//   spans, 8 bytes each: f32 floor, f32 ceil. Ascending, not overlapping.
// A tile with no record is flat open ground: floor 0, no ceiling.

#include <stdint.h>

#define WORLD_SPANS_MAGIC          "MMOSPANS"
#define WORLD_SPANS_MAGIC_LEN      8
#define WORLD_SPANS_VERSION        1
#define WORLD_SPANS_HEADER_BYTES   32
#define WORLD_SPANS_TILE_BYTES     12
#define WORLD_SPANS_SPAN_BYTES     8
#define WORLD_SPANS_MAX_TILES      16000000u
#define WORLD_SPANS_MAX_SPANS      64000000u
#define WORLD_SPANS_MAX_PER_TILE   8

#define WORLD_BODY_HEIGHT          40.0f
#define WORLD_STEP_HEIGHT          12.0f
#define WORLD_Z_TOLERANCE          1.0f
#define WORLD_SPAN_OPEN_CEIL       1.0e9f

#endif /* WORLD_SPANS_FORMAT_H */
```

`mmo_server/common/include/world_spans.h`:

```c
#ifndef WORLD_SPANS_H
#define WORLD_SPANS_H

// What can be stood on at a world point, and what a body can reach.
// Pure data and arithmetic: no logging, no globals beyond the loaded file.
// Every function fails closed outside the world and on non-finite input.

typedef struct {
	float floor;
	float ceil;
} world_span;

// Set the world extent and drop any loaded spans (flat ground everywhere).
void world_spans_init(int width_tiles, int height_tiles, int tile_size);

// Load the sidecar. It must match the extent given to world_spans_init.
// Returns 1 on success. On failure returns 0 and keeps the old tables.
int world_spans_load(const char* path);

int world_spans_loaded(void);
void world_spans_shutdown(void);

// Copy up to max spans of the tile holding (x, y). Returns the count.
int world_spans_at(float x, float y, world_span* out, int max);

// Returns 1 (success) when a floor within one step of from_z has headroom.
int world_spans_reach(float x, float y, float from_z, float* out_z);

// As reach, for the body box: all four corners must hold the same floor.
int world_spans_reach_box(float x, float y, float half, float from_z,
                          float* out_z);

// Walk the box from (x0, y0, z0) to (x1, y1) in half-tile samples.
// Returns 1 when every sample is reachable; out_z is the final floor.
int world_spans_walk(float x0, float y0, float z0, float x1, float y1,
                     float half, float* out_z);

// Nearest usable floor to hint_z, with no step limit. Returns 0 if none.
int world_spans_snap(float x, float y, float hint_z, float* out_z);

// All four corner columns hold a body standing at z.
int world_spans_fits_box(float x, float y, float half, float z);

// All four corner columns leave room for a body at z, floor possibly far below.
int world_spans_free_box(float x, float y, float half, float z);

// Highest floor in [z_lo, z_hi] of the centre column the box fits on.
int world_spans_floor_between(float x, float y, float half, float z_lo,
                              float z_hi, float* out_z);

// z is inside some span's clear interval (a point, not a body).
int world_spans_free_point(float x, float y, float z);

#endif /* WORLD_SPANS_H */
```

```c
#ifndef WORLD_SPANS_FIXTURE_H
#define WORLD_SPANS_FIXTURE_H

// Writes small span sidecars for tests, including deliberately bad ones.

#include "world_spans.h"
#include "world_spans_format.h"

#include <assert.h>
#include <stdint.h>
#include <stdio.h>
#include <string.h>
#include <unistd.h>

#define FIX_W 64
#define FIX_H 64
#define FIX_TILE 16
#define FIX_T(x, y) ((uint32_t)((y) * FIX_W + (x)))
#define FIX_CX(tx) (((float)(tx) + 0.5f) * FIX_TILE)
#define FIX_OPEN WORLD_SPANS_OPEN_CEIL

typedef struct {
	uint32_t index;
	uint32_t first;
	uint32_t count;
} fix_record;

// trim drops that many bytes from the end of the file.
static inline void fix_write(const char* path, int w, int h, int tile,
                             const fix_record* recs, uint32_t nrec,
                             const world_span* spans, uint32_t nspan,
                             uint32_t version, size_t trim) {
	FILE* f = fopen(path, "wb");

	assert(f);
	fwrite(WORLD_SPANS_MAGIC, 1, WORLD_SPANS_MAGIC_LEN, f);
	fwrite(&version, 4, 1, f);
	fwrite(&w, 4, 1, f);
	fwrite(&h, 4, 1, f);
	fwrite(&tile, 4, 1, f);
	fwrite(&nrec, 4, 1, f);
	fwrite(&nspan, 4, 1, f);
	fwrite(recs, sizeof(fix_record), nrec, f);
	fwrite(spans, sizeof(world_span), nspan, f);
	fclose(f);

	if(trim) {
		long size;

		f = fopen(path, "rb");
		fseek(f, 0, SEEK_END);
		size = ftell(f);
		fclose(f);
		assert(truncate(path, size - (long)trim) == 0);
	}
}

// One ramp (tiles 10-13 on row 5 rise 0, 8, 16, 24), a tile at 60, a bridge
// over open ground at tile 20, a low ceiling at 22, no floor at 24, and a
// platform at 100 on tile 29 (next to open ground at tile 30).
static inline void fix_write_city(const char* path) {
	static const fix_record recs[] = {
		{FIX_T(10, 5), 0, 1}, {FIX_T(11, 5), 1, 1}, {FIX_T(12, 5), 2, 1},
		{FIX_T(13, 5), 3, 1}, {FIX_T(14, 5), 4, 1}, {FIX_T(20, 5), 5, 2},
		{FIX_T(22, 5), 7, 1}, {FIX_T(24, 5), 8, 0}, {FIX_T(29, 5), 8, 1},
	};
	static const world_span spans[] = {
		{0, FIX_OPEN}, {8, FIX_OPEN}, {16, FIX_OPEN}, {24, FIX_OPEN},
		{60, FIX_OPEN}, {0, 70}, {74, FIX_OPEN}, {0, 30}, {100, FIX_OPEN},
	};

	fix_write(path, FIX_W, FIX_H, FIX_TILE, recs, 9, spans, 9,
	          WORLD_SPANS_VERSION, 0);
}

#endif /* WORLD_SPANS_FIXTURE_H */
```

```c
// Check the span lookups: flat default, ramp, step, bridge, headroom, loader.

#define _POSIX_C_SOURCE 200809L
#include "world_spans_fixture.h"

#include <assert.h>
#include <math.h>
#include <stdio.h>

#define PATH "/tmp/world_spans_test.bin"
#define Y5 FIX_CX(5)

static void test_flat_default(void) {
	float z = -1.0f;

	world_spans_init(FIX_W, FIX_H, FIX_TILE);
	assert(!world_spans_loaded());
	assert(world_spans_reach(FIX_CX(2), FIX_CX(2), 0.0f, &z) && z == 0.0f);
	assert(world_spans_reach(FIX_CX(2), FIX_CX(2), 11.9f, &z) && z == 0.0f);
	assert(!world_spans_reach(FIX_CX(2), FIX_CX(2), 12.1f, &z));
	assert(!world_spans_reach(FIX_CX(2), FIX_CX(2), 100.0f, &z));
	assert(!world_spans_reach(-1.0f, 8.0f, 0.0f, &z));
	assert(!world_spans_reach(1024.0f, 8.0f, 0.0f, &z));
	assert(!world_spans_reach(NAN, 8.0f, 0.0f, &z));
	assert(!world_spans_reach(8.0f, 8.0f, NAN, &z));
}

static void test_ramp(void) {
	float z = -1.0f;

	assert(world_spans_walk(FIX_CX(10), Y5, 0.0f, FIX_CX(13), Y5, 6.0f, &z));
	assert(z == 24.0f);
	assert(world_spans_walk(FIX_CX(13), Y5, 24.0f, FIX_CX(10), Y5, 6.0f, &z));
	assert(z == 0.0f);

	// 24 -> 60 is a 36 unit step: not walkable
	assert(!world_spans_walk(FIX_CX(13), Y5, 24.0f, FIX_CX(14), Y5, 6.0f, &z));
}

static void test_bridge(void) {
	world_span s[WORLD_SPANS_MAX_PER_TILE];
	float z = -1.0f;

	assert(world_spans_at(FIX_CX(20), Y5, s, WORLD_SPANS_MAX_PER_TILE) == 2);
	assert(world_spans_reach(FIX_CX(20), Y5, 0.0f, &z) && z == 0.0f);
	assert(world_spans_reach(FIX_CX(20), Y5, 74.0f, &z) && z == 74.0f);
	assert(!world_spans_reach(FIX_CX(20), Y5, 40.0f, &z));
	assert(world_spans_snap(FIX_CX(20), Y5, 80.0f, &z) && z == 74.0f);
	assert(world_spans_snap(FIX_CX(20), Y5, 5.0f, &z) && z == 0.0f);

	// walking under the deck stays on the ground
	assert(world_spans_walk(FIX_CX(19), Y5, 0.0f, FIX_CX(21), Y5, 6.0f, &z));
	assert(z == 0.0f);
}

static void test_headroom_and_no_floor(void) {
	float z = -1.0f;

	// ceiling 30 over floor 0: less than a body
	assert(!world_spans_reach(FIX_CX(22), Y5, 0.0f, &z));
	assert(!world_spans_snap(FIX_CX(22), Y5, 0.0f, &z));

	// a record with no spans: nothing to stand on
	assert(!world_spans_reach(FIX_CX(24), Y5, 0.0f, &z));
	assert(!world_spans_snap(FIX_CX(24), Y5, 0.0f, &z));
}

static void test_free_and_landing(void) {
	float z = -1.0f;

	// in the air above flat ground is free; inside a taller tile is not
	assert(world_spans_free_box(FIX_CX(2), FIX_CX(2), 6.0f, 20.0f));
	assert(world_spans_fits_box(FIX_CX(2), FIX_CX(2), 6.0f, 0.0f));
	assert(!world_spans_fits_box(FIX_CX(2), FIX_CX(2), 6.0f, 20.0f));
	assert(!world_spans_free_box(FIX_CX(14), Y5, 6.0f, 24.0f));
	assert(world_spans_free_box(FIX_CX(14), Y5, 6.0f, 50.0f));

	// the deck leaves 70 over the ground, so a body at 31 would hit it
	assert(world_spans_free_box(FIX_CX(20), Y5, 6.0f, 30.0f));
	assert(!world_spans_free_box(FIX_CX(20), Y5, 6.0f, 31.0f));

	// falling from 110 toward 90 across the platform at 100 lands on it
	assert(world_spans_floor_between(FIX_CX(29), Y5, 6.0f, 90.0f, 122.0f, &z));
	assert(z == 100.0f);
	assert(!world_spans_floor_between(FIX_CX(29), Y5, 6.0f, 101.0f, 122.0f, &z));

	// a point inside the gap under the deck, and one inside the deck's slab
	assert(world_spans_free_point(FIX_CX(20), Y5, 40.0f));
	assert(!world_spans_free_point(FIX_CX(20), Y5, 72.0f));
	assert(world_spans_free_point(FIX_CX(20), Y5, 80.0f));
	assert(!world_spans_free_point(FIX_CX(24), Y5, 10.0f));
}

static void expect_load_fails(const char* what) {
	float z = -1.0f;

	assert(!world_spans_load(PATH));

	// the previous tables survive a refused load
	assert(world_spans_loaded());
	assert(world_spans_reach(FIX_CX(11), Y5, 8.0f, &z) && z == 8.0f);
	(void)what;
}

static void test_loader_rejects_bad_files(void) {
	static const fix_record one[] = {{FIX_T(1, 1), 0, 1}};
	static const fix_record reversed[] = {{FIX_T(2, 1), 0, 1}, {FIX_T(1, 1), 1, 1}};
	static const fix_record two[] = {{FIX_T(1, 1), 0, 2}};
	static const world_span flat[] = {{0, FIX_OPEN}};
	static const world_span flat2[] = {{0, FIX_OPEN}, {0, FIX_OPEN}};
	static const world_span overlap[] = {{0, 50}, {40, FIX_OPEN}};
	static const world_span nan_span[] = {{NAN, FIX_OPEN}};
	static const world_span inverted[] = {{50, 10}};

	fix_write_city(PATH);
	assert(world_spans_load(PATH) && world_spans_loaded());

	fix_write(PATH, FIX_W, FIX_H, FIX_TILE, one, 1, flat, 1, 2, 0);
	expect_load_fails("version");
	fix_write(PATH, FIX_W + 1, FIX_H, FIX_TILE, one, 1, flat, 1, 1, 0);
	expect_load_fails("width");
	fix_write(PATH, FIX_W, FIX_H, FIX_TILE + 1, one, 1, flat, 1, 1, 0);
	expect_load_fails("tile size");
	fix_write(PATH, FIX_W, FIX_H, FIX_TILE, one, 1, flat, 1, 1, 1);
	expect_load_fails("truncated");
	fix_write(PATH, FIX_W, FIX_H, FIX_TILE, reversed, 2, flat2, 2, 1, 0);
	expect_load_fails("unsorted");
	fix_write(PATH, FIX_W, FIX_H, FIX_TILE, two, 1, overlap, 2, 1, 0);
	expect_load_fails("overlap");
	fix_write(PATH, FIX_W, FIX_H, FIX_TILE, one, 1, nan_span, 1, 1, 0);
	expect_load_fails("nan");
	fix_write(PATH, FIX_W, FIX_H, FIX_TILE, one, 1, inverted, 1, 1, 0);
	expect_load_fails("inverted");
	assert(!world_spans_load("/tmp/does_not_exist_spans.bin"));
}

int main(void) {
	test_flat_default();
	world_spans_init(FIX_W, FIX_H, FIX_TILE);
	fix_write_city(PATH);
	assert(world_spans_load(PATH));
	test_ramp();
	test_bridge();
	test_headroom_and_no_floor();
	test_free_and_landing();
	test_loader_rejects_bad_files();
	world_spans_shutdown();
	assert(!world_spans_loaded());
	puts("world_spans_test: all tests passed");
	return 0;
}
```

```c
#include "world_spans_format.h"

#include <math.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
	uint32_t tile_index;
	uint32_t first_span;
	uint32_t span_count;
} tile_record;

typedef struct {
	int32_t width;
	int32_t height;
	int32_t tile_size;
	uint32_t tile_count;
	uint32_t span_count;
} spans_header;

static int g_width = 0;
static int g_height = 0;
static float g_tile = 0.0f;
static tile_record* g_tiles = NULL;
static world_span* g_spans = NULL;
static uint32_t g_tile_count = 0;
static uint32_t g_span_count = 0;

static void free_tables(void) {
	free(g_tiles);
	free(g_spans);
	g_tiles = NULL;
	g_spans = NULL;
	g_tile_count = 0;
	g_span_count = 0;
}

void world_spans_init(int width_tiles, int height_tiles, int tile_size) {
	free_tables();
	g_width = width_tiles;
	g_height = height_tiles;
	g_tile = (float)tile_size;
}

void world_spans_shutdown(void) {
	free_tables();
	g_width = 0;
	g_height = 0;
	g_tile = 0.0f;
}

int world_spans_loaded(void) {
	return g_tiles != NULL;

// The tile holding a world point. Returns 0 when it is not inside the world.
static int tile_of(float x, float y, int* tx, int* ty) {
	if(g_width <= 0 || g_height <= 0 || !(g_tile > 0.0f))
		return 0;
	if(!isfinite(x) || !isfinite(y))
		return 0;

	float fx = x / g_tile;
	float fy = y / g_tile;

	if(!(fx >= 0.0f) || !(fy >= 0.0f))
		return 0;
	if(!(fx < (float)g_width) || !(fy < (float)g_height))
		return 0;

	*tx = (int)fx;
	*ty = (int)fy;
	return 1;
}

static const tile_record* find_tile(uint32_t index) {
	uint32_t lo = 0;
	uint32_t hi = g_tile_count;

	while(lo < hi) {
		uint32_t mid = lo + (hi - lo) / 2;

		if(g_tiles[mid].tile_index < index)
			lo = mid + 1;
		else
			hi = mid;
	}
	if(lo < g_tile_count && g_tiles[lo].tile_index == index)
		return &g_tiles[lo];
	return NULL;
}

int world_spans_at(float x, float y, world_span* out, int max) {
	int tx = 0;
	int ty = 0;

	if(max < 1 || !tile_of(x, y, &tx, &ty))
		return 0;

	const tile_record* rec = find_tile((uint32_t)ty * (uint32_t)g_width + (uint32_t)tx);

	if(!rec) {
		out[0].floor = 0.0f;
		out[0].ceil = WORLD_SPAN_OPEN_CEIL;
		return 1;
	}

	int count = (int)rec->span_count;

	if(count > max)
		count = max;
	if(count > 0)
		memcpy(out, &g_spans[rec->first_span], (size_t)count * sizeof(world_span));
	return count;
}

static int span_usable(const world_span* s) {
	return s->ceil - s->floor >= WORLD_BODY_HEIGHT;
}

int world_spans_reach(float x, float y, float from_z, float* out_z) {
	world_span spans[WORLD_SPANS_MAX_PER_TILE];
	int best = -1;
	float best_gap = 0.0f;

	if(!isfinite(from_z))
		return 0;

	int count = world_spans_at(x, y, spans, WORLD_SPANS_MAX_PER_TILE);

	for(int i = 0; i < count; i++) {
		float gap = fabsf(spans[i].floor - from_z);

		if(!span_usable(&spans[i]) || gap > WORLD_STEP_HEIGHT)
			continue;
		if(best < 0 || gap < best_gap) {
			best = i;
			best_gap = gap;
		}
	}
	if(best < 0)
		return 0;
	if(out_z)
		*out_z = spans[best].floor;
	return 1;
}

// Does some span of this column hold a body standing at z?
static int column_holds(float x, float y, float z) {
	world_span spans[WORLD_SPANS_MAX_PER_TILE];
	int count = world_spans_at(x, y, spans, WORLD_SPANS_MAX_PER_TILE);

	for(int i = 0; i < count; i++) {
		if(fabsf(spans[i].floor - z) > WORLD_STEP_HEIGHT)
			continue;
		if(spans[i].ceil - z >= WORLD_BODY_HEIGHT)
			return 1;
	}
	return 0;
}

// Does some span of this column leave room for a body at z (floor anywhere
// at or below one step above z)?
static int column_free(float x, float y, float z) {
	world_span spans[WORLD_SPANS_MAX_PER_TILE];
	int count = world_spans_at(x, y, spans, WORLD_SPANS_MAX_PER_TILE);

	for(int i = 0; i < count; i++) {
		if(spans[i].floor > z + WORLD_STEP_HEIGHT)
			continue;
		if(spans[i].ceil - z >= WORLD_BODY_HEIGHT)
			return 1;
	}
	return 0;
}

int world_spans_fits_box(float x, float y, float half, float z) {
	if(!isfinite(z) || !isfinite(half))
		return 0;
	return column_holds(x - half, y - half, z) && column_holds(x + half, y - half, z) &&
	       column_holds(x - half, y + half, z) && column_holds(x + half, y + half, z);
}

int world_spans_free_box(float x, float y, float half, float z) {
	if(!isfinite(z) || !isfinite(half))
		return 0;
	return column_free(x - half, y - half, z) && column_free(x + half, y - half, z) &&
	       column_free(x - half, y + half, z) && column_free(x + half, y + half, z);
}

int world_spans_reach_box(float x, float y, float half, float from_z,
                          float* out_z) {
	float z = 0.0f;

	if(!world_spans_reach(x, y, from_z, &z))
		return 0;
	if(!world_spans_fits_box(x, y, half, z))
		return 0;
	if(out_z)
		*out_z = z;
	return 1;
}

int world_spans_floor_between(float x, float y, float half, float z_lo,
                              float z_hi, float* out_z) {
	world_span spans[WORLD_SPANS_MAX_PER_TILE];
	int best = -1;

	if(!isfinite(z_lo) || !isfinite(z_hi))
		return 0;

	int count = world_spans_at(x, y, spans, WORLD_SPANS_MAX_PER_TILE);

	for(int i = 0; i < count; i++) {
		float f = spans[i].floor;

		if(!span_usable(&spans[i]) || f < z_lo || f > z_hi)
			continue;
		if(!world_spans_fits_box(x, y, half, f))
			continue;
		if(best < 0 || f > spans[best].floor)
			best = i;
	}
	if(best < 0)
		return 0;
	if(out_z)
		*out_z = spans[best].floor;
	return 1;
}

int world_spans_free_point(float x, float y, float z) {
	world_span spans[WORLD_SPANS_MAX_PER_TILE];

	if(!isfinite(z))
		return 0;

	int count = world_spans_at(x, y, spans, WORLD_SPANS_MAX_PER_TILE);

	for(int i = 0; i < count; i++) {
		if(spans[i].floor <= z && z < spans[i].ceil)
			return 1;
	}
	return 0;
}

// Refuse paths needing more samples than this, as the 2D path check does.
#define WALK_MAX_STEPS 256

int world_spans_walk(float x0, float y0, float z0, float x1, float y1,
                     float half, float* out_z) {
	if(!isfinite(x0) || !isfinite(y0) || !isfinite(z0))
		return 0;
	if(!isfinite(x1) || !isfinite(y1) || !isfinite(half) || !(g_tile > 0.0f))
		return 0;

	float dx = x1 - x0;
	float dy = y1 - y0;
	float distance = sqrtf(dx * dx + dy * dy);
	int steps = (int)(distance / (g_tile * 0.5f)) + 1;
	float z = z0;

	if(steps > WALK_MAX_STEPS)
		return 0;

	for(int i = 1; i <= steps; i++) {
		float t = (float)i / (float)steps;

		if(!world_spans_reach_box(x0 + dx * t, y0 + dy * t, half, z, &z))
			return 0;
	}
	if(out_z)
		*out_z = z;
	return 1;
}

int world_spans_snap(float x, float y, float hint_z, float* out_z) {
	world_span spans[WORLD_SPANS_MAX_PER_TILE];
	int best = -1;
	float best_gap = 0.0f;

	if(!isfinite(hint_z))
		return 0;

	int count = world_spans_at(x, y, spans, WORLD_SPANS_MAX_PER_TILE);

	for(int i = 0; i < count; i++) {
		float gap = fabsf(spans[i].floor - hint_z);

		if(!span_usable(&spans[i]))
			continue;
		if(best < 0 || gap < best_gap) {
			best = i;
			best_gap = gap;
		}
	}
	if(best < 0)
		return 0;
	if(out_z)
		*out_z = spans[best].floor;
	return 1;
}

static int read_header(FILE* f, spans_header* h) {
	char magic[WORLD_SPANS_MAGIC_LEN];
	uint32_t version = 0;

	if(fread(magic, 1, sizeof(magic), f) != sizeof(magic))
		return 0;
	if(memcmp(magic, WORLD_SPANS_MAGIC, sizeof(magic)) != 0)
		return 0;
	if(fread(&version, 4, 1, f) != 1 || version != WORLD_SPANS_VERSION)
		return 0;
	if(fread(&h->width, 4, 1, f) != 1 || fread(&h->height, 4, 1, f) != 1)
		return 0;
	if(fread(&h->tile_size, 4, 1, f) != 1)
		return 0;
	return fread(&h->tile_count, 4, 1, f) == 1 && fread(&h->span_count, 4, 1, f) == 1;
}

static int header_fits(const spans_header* h) {
	if(h->width != g_width || h->height != g_height)
		return 0;
	if((float)h->tile_size != g_tile)
		return 0;
	return h->tile_count <= WORLD_SPANS_MAX_TILES &&
	       h->span_count <= WORLD_SPANS_MAX_SPANS;
}

static int span_valid(const world_span* s) {
	return isfinite(s->floor) && isfinite(s->ceil) && s->ceil > s->floor;
}

// Records sorted and contiguous, spans finite, ascending and not overlapping.
static int tables_valid(const tile_record* tiles, uint32_t tile_count,
                        const world_span* spans, uint32_t span_count) {
	uint64_t cells = (uint64_t)g_width * (uint64_t)g_height;
	uint32_t next_span = 0;

	for(uint32_t i = 0; i < tile_count; i++) {
		const tile_record* t = &tiles[i];

		if(t->tile_index >= cells)
			return 0;
		if(i > 0 && t->tile_index <= tiles[i - 1].tile_index)
			return 0;
		if(t->span_count > WORLD_SPANS_MAX_PER_TILE || t->first_span != next_span)
			return 0;
		if(t->span_count > span_count - next_span)
			return 0;

		for(uint32_t k = 0; k < t->span_count; k++) {
			const world_span* s = &spans[t->first_span + k];

			if(!span_valid(s))
				return 0;
			if(k > 0 && s->floor < spans[t->first_span + k - 1].ceil)
				return 0;
		}
		next_span += t->span_count;
	}
	return next_span == span_count;
}

// Bytes the header says the file holds, or 0 when that overflows.
static long expected_size(const spans_header* h) {
	return (long)WORLD_SPANS_HEADER_BYTES +
	       (long)h->tile_count * WORLD_SPANS_TILE_BYTES +
	       (long)h->span_count * WORLD_SPANS_SPAN_BYTES;
}

static int file_size_is(FILE* f, long want) {
	long here = ftell(f);

	if(here < 0 || fseek(f, 0, SEEK_END) != 0)
		return 0;

	long size = ftell(f);

	return size == want && fseek(f, here, SEEK_SET) == 0;
}

int world_spans_load(const char* path) {
	spans_header h;
	FILE* f = fopen(path, "rb");

	if(!f)
		return 0;
	if(g_width <= 0 || !read_header(f, &h) || !header_fits(&h)) {
		fclose(f);
		return 0;
	}
	if(!file_size_is(f, expected_size(&h))) {
		fclose(f);
		return 0;
	}

	// the loaded flag is "has tiles", so a file with none still needs one
	tile_record* tiles = calloc(h.tile_count ? h.tile_count : 1, sizeof(*tiles));
	world_span* spans = calloc(h.span_count ? h.span_count : 1, sizeof(*spans));
	int ok = tiles && spans &&
	         fread(tiles, sizeof(*tiles), h.tile_count, f) == h.tile_count &&
	         fread(spans, sizeof(*spans), h.span_count, f) == h.span_count &&
	         tables_valid(tiles, h.tile_count, spans, h.span_count);

	fclose(f);
	if(!ok) {
		free(tiles);
		free(spans);
		return 0;
	}

	free_tables();
	g_tiles = tiles;
	g_spans = spans;
	g_tile_count = h.tile_count;
	g_span_count = h.span_count;
	return 1;
}
```

```c
// One fixed step of walking, jumping and falling against the span layer.

#include "world_motion.h"
#include "world_spans.h"
#include "world_spans_format.h"

// Follow the floor, walk off an edge, or refuse a wall.
static int step_grounded(vertical_state* n, float x, float y, float half) {
	float floor_z = 0.0f;

	if(world_spans_reach_box(x, y, half, n->z, &floor_z)) {
		n->z = floor_z;
		return 1;
	}
	if(!world_spans_free_box(x, y, half, n->z))
		return 0;

	// the floor fell away: start falling from rest
	n->grounded = 0;
	n->vz = 0.0f;
	return 1;
}

static int step_airborne(vertical_state* n, float x, float y, float half) {
	float land = 0.0f;

	if(!world_spans_free_box(x, y, half, n->z))
		return 0;

	n->vz -= WORLD_GRAVITY * WORLD_VSTEP;
	if(n->vz < -WORLD_TERMINAL_SPEED)
		n->vz = -WORLD_TERMINAL_SPEED;

	float next_z = n->z + n->vz * WORLD_VSTEP;

	if(n->vz > 0.0f && !world_spans_free_box(x, y, half, next_z)) {
		// the head met a ceiling
		n->vz = 0.0f;
		next_z = n->z;
	}
	if(n->vz <= 0.0f &&
	   world_spans_floor_between(x, y, half, next_z, n->z + WORLD_STEP_HEIGHT, &land)) {
		n->z = land;
		n->vz = 0.0f;
		n->grounded = 1;
		return 1;
	}
	n->z = next_z;
	return 1;
}

int vertical_step(vertical_state* s, float x, float y, float half, int jump) {
	vertical_state n = *s;

	if(!isfinite(x) || !isfinite(y) || !isfinite(n.z) || !isfinite(n.vz))
		return 0;

	if(n.grounded && jump) {
		n.vz = WORLD_JUMP_SPEED;
		n.grounded = 0;
	}

	int ok = n.grounded ? step_grounded(&n, x, y, half)
	                    : step_airborne(&n, x, y, half);

	if(!ok)
		return 0;
	*s = n;
	return 1;
}
```

```c
#define MOVE_MAX_VSTEPS 128

// The simulated state nearest `steps` whose height is within tolerance of
// to_z, searching outward by WORLD_AIR_SLACK_STEPS. -1 when none matches.
static int match_state(const vertical_state* states, int steps, int last, float to_z) {
	for(int d = 0; d <= WORLD_AIR_SLACK_STEPS; d++) {
		int pick[2] = {steps + d, steps - d};

		for(int p = 0; p < 2; p++) {
			int k = pick[p];

			if(k < 1 || k > last)

			if(fabsf(to_z - states[k].z) <= tol)
				return k;
		}
	}
	return -1;
}
```

```python
"""Turn per-tile ray samples into walkable spans. Pure: no bpy."""


def cluster_floors(cells, min_cells=8, gap=6.0):
    """Group upward-facing hits into floors; keep those most of a tile has.

    cells is one list per sub-sample of (z, ceil) hits. A floor needs hits from
    at least min_cells sub-samples, so a 0.2 m wall top does not count.
    """
    hits = sorted((z, ceil, i) for i, cell in enumerate(cells) for z, ceil in cell)
    clusters, current = [], []
    for hit in hits:
        if current and hit[0] - current[-1][0] > gap:
            clusters.append(current)
            current = []
        current.append(hit)
    if current:
        clusters.append(current)

    spans = []
    for cluster in clusters:
        if len({h[2] for h in cluster}) < min_cells:
            continue
        zs = sorted(h[0] for h in cluster)
        spans.append((zs[len(zs) // 2], min(h[1] for h in cluster)))
    return spans


def clip_spans(spans, blockers, body=40.0, step=12.0):
    """Drop a span when a solid rises past a step and starts inside the body."""
    kept = []
    for floor, ceil in spans:
        blocked = any(hi > floor + step and lo < floor + body for lo, hi in blockers)
        if not blocked:
            kept.append((floor, ceil))
    return kept


def usable(spans, body=40.0):
    return [(f, c) for f, c in spans if c - f >= body]
```

```c
#include "world/world_pick.h"
#include "world_spans.h"

#include <math.h>

#define PICK_STEP 2.0f
#define PICK_BISECT 8

static int free_at(const float p[3]) {
	return world_spans_free_point(p[0], p[1], p[2]);
}

int world_pick_ground(const float origin[3], const float dir[3], float max_dist,
                      float out[3]) {
	float prev[3] = {origin[0], origin[1], origin[2]};

	if(!free_at(prev))
		return 0;

	for(float t = PICK_STEP; t <= max_dist; t += PICK_STEP) {
		float p[3] = {origin[0] + dir[0] * t, origin[1] + dir[1] * t,
		              origin[2] + dir[2] * t};

		if(free_at(p)) {
			prev[0] = p[0];
			prev[1] = p[1];
			prev[2] = p[2];
			continue;
		}

		float lo = t - PICK_STEP;
		float hi = t;

		for(int i = 0; i < PICK_BISECT; i++) {
			float mid = (lo + hi) * 0.5f;
			float m[3] = {origin[0] + dir[0] * mid, origin[1] + dir[1] * mid,
			              origin[2] + dir[2] * mid};

			if(free_at(m))
				lo = mid;
			else
				hi = mid;
		}
		out[0] = origin[0] + dir[0] * lo;
		out[1] = origin[1] + dir[1] * lo;
		out[2] = origin[2] + dir[2] * lo;
		return 1;
	}
	return 0;
}
```
